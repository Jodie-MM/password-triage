# Password Triage 🚑

A Python password strength checker, inspired by my time as an emergency medical technician with London Ambulance Service.

Every password is a "patient". The program assesses it and lists any "symptoms", such as being too short or having no numbers.

🚧 **Work in progress.** I'm building this step by step as I learn Python. See the `learning-steps` folder for how it grew.
